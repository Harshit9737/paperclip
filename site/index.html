FAQ

A few things you might be wondering.

This site is a public preview of the concept. Follow the repository for implementation updates.

View on GitHub
How will King's AI remember what matters?

The concept is durable preferences, goals, and project context that carry across conversations, with controls to inspect, edit, and delete saved memories.

Will I be able to choose the AI model?

Provider flexibility is part of the vision, including options such as OpenAI, Anthropic, and OpenRouter. Check the repository to see current implementation status.

Where will I be able to use it?

The product direction includes a terminal interface and connected chat channels. This GitHub Pages site is only a static landing-page preview.

Is it intended for security work?

The intended audience includes responsible developers and security researchers. Only assess systems you own or have explicit permission to test.
